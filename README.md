# Расширения Luma — StatickBoost

Эта ветка содержит подписанные каталоги тем и модулей для Luma.

- `catalog.json` — подписанный каталог тем, поддерживаемый начиная с версии Luma 0.5.2.
- `themes/<id>/<версия>.json` — загружаемые пакеты тем.
- "modules.json" — подписанный каталог модулей, поддерживаемый начиная с версии Luma 0.5.4.
- `modules/<id>/<версия>/Luma.Module.*.dll` — собственно исполняемые модули, загружаемые отдельно из установщика приложения.

В Luma откройте "Расширения", выберите модуль и загрузите его. После первой установки справа появляется кнопка "Модули". Она открывает установленные инструменты. Установленные модули могут использоваться автономно и могут быть обновлены, отключены или удалены через каталог.

Начиная с версии Luma 0.5.7, расширения открываются с отдельными разделами функций и тем, каждый из которых содержит свой собственный установленный фильтр и обновление каталога. Для повторного подключения к VPN и игровой панели требуется Luma версии 0.5.7; в Мониторинге и Диагностике сохраняются исходные пакеты и поддерживается Luma версии 0.5.4 или более поздней.

Повторное подключение к VPN включено.

## Игровая панель 1.1.0

Участники комнаты, IP, пинг и состояние выровнены по колонкам. Добавлено компактное меню поверх игры с данными VPN и комнаты, статусами участников и копированием IP.

Обновите модуль в «Расширения → Функции», откройте «Игровую панель» и включите горячую клавишу. По умолчанию Ctrl+Shift+L показывает и скрывает меню; можно выбрать другое сочетание, если оно занято. Меню работает, пока Luma скрыта в трее. После перезапуска Luma откройте игровую панель один раз для регистрации сочетания.

Поддерживаются оконные и безрамочные игры. Для эксклюзивного полноэкранного режима выберите безрамочный режим. Модуль не внедряется в процесс игры. При отключении или удалении модуля меню закрывается, а сочетание освобождается. Сохранённый список игр переносится автоматически.

Нужна Luma 0.5.7 или новее; переустановка приложения не требуется. Сеть и маршруты панель не меняет, снижение задержки не обещает. Каталог подписан StatickBoost, перед загрузкой проверяются подпись и SHA-256 пакета.

### Исправление 1.1.1

Исправлена ошибка «Внешние библиотеки модуля не поддерживаются» при включении горячей клавиши в Luma 0.5.7. Модуль разрешает только используемые им user32.dll и kernel32.dll по абсолютным путям системной папки Windows; сторонние DLL из пакета не требуются. Проверка подписей и пакетов в приложении не менялась.

Для получения исправления: «Расширения → Функции → Обновить каталог → Игровая панель → Обновить модуль». Версия модуля должна стать 1.1.1. Откройте игровую панель и включите горячую клавишу. Переустановка Luma не нужна. Исправление проверено с фактическим загрузчиком модулей исходной Luma 0.5.7: включение, открытие и скрытие меню, конфликты клавиш и освобождение сочетания при остановке.
