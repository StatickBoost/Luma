# Дополнительные темы Luma

Официальный каталог StatickBoost. Требуется **Luma 0.5.2 или новее**.

Откройте приложение → **Расширения** → **Обновить каталог** → **Установить** → **Применить**.

| Тема | Оформление |
|---|---|
| Графит | Матовая тёмная тема с синими акцентами |
| Жемчуг | Тёплая светлая тема |
| Сакура | Светлая розовая тема |
| Лес | Тёмная зелёная тема с мятными акцентами |
| Северное сияние | Стекло с изумрудными и фиолетовыми оттенками |
| Закат | Стекло с янтарными и малиновыми оттенками |

Эта ветка содержит только каталог и пакеты тем. Обновления приложения размещаются отдельно в GitHub Releases.

## Файлы

- `catalog.json` — подписанный каталог с версиями, размером и SHA-256 каждого пакета.
- `themes/<id>/<version>.json` — пакет цветов и параметров фона. В нём нет DLL, XAML, скриптов или запускаемых файлов.

Программа проверяет подпись StatickBoost, целостность пакета и совместимость с версией приложения. Установленные темы сохраняются локально и работают без доступа к GitHub. Для удаления используется кнопка «Удалить»; при удалении активной темы включается её встроенная основа.
